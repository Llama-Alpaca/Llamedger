# UI 结构说明（线框图）

> 这份文档是**根据实际布局 XML 提取**的，不是凭记忆画的。改 UI 时可以直接引用：

## ⑧ 流水条目 `item_txn.xml`（①②页共用）

```
┌───────────────────────────────────────────┐
│ 美团外卖 [角标]                  -¥35.50   │ 15sp / 16sp 粗体
│ 餐饮 · 尾号1234 · 自动             12:30   │ 12sp 灰 / 11sp 灰
└───────────────────────────────────────────┘
```
收入为 `+¥`（绿色），支出为 `-¥`（深色），转账不带正负号（灰色）。
角标按状态显示：转帐 / 转账·已配对 / 退款冲抵 / 已撤销 / 待确认退款 / 已退¥x / 待核对。
已撤销的条目文字加删除线并变灰。
